# Hi, I'm Craig 👋

### AI, machine learning, and the systems that make them useful.

I'm **Craig Lionel Roberts**. My academic background spans graduate study in Artificial Intelligence at **Northeastern University, Boston**, and a Computer Science and Engineering degree focused on AI and ML from **VIT Bhopal**.

I build projects across applied machine learning, natural language processing, and model serving. I’m interested in the full path from an idea to a working application: preparing data, evaluating models, building interfaces, and understanding deployment tradeoffs.

## Selected projects

| Project | What I’m building |
| --- | --- |
| [KubeServe](https://github.com/CR1502/kubeserve) | A local Kubernetes LLM-serving setup comparing vLLM with a FastAPI + Transformers baseline, with CPU benchmarks, autoscaling, and rolling-update experiments. |
| [SpectraDrift](https://github.com/CR1502/SpectraDrift) | Drift detection for industrial sensor time series using PCA reconstruction scores and rolling statistical tests, evaluated on the Tennessee Eastman Process benchmark. |
| [Candidate Recommender](https://github.com/CR1502/CandidateRecommender) | A resume-to-job matching application combining semantic embeddings, skill coverage, and experience signals, with local LLM assessments and a FastAPI + React interface. |
| [NomadAI](https://github.com/CR1502/NomadAI) | A Streamlit travel discovery and itinerary application combining community discussions, place search, retrieval, and optional local or cloud AI generation. |
